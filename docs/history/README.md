- `DESIGN-v1.md`: the first top-level design, including its decisions table and phase roadmap.
- `DSH-INTEGRATION.md`: how each phase plugged into DSH, with demo evidence per phase. Still the best reference for how a DSH API behaved when it was verified; `docs/dsh.md` keeps what is still relied on.
- `FORMAL-TEST.md`: the plan for the formal test `formal-2`, dropped with the redesign.
- `primer-preview.md`: the prompt texts of the Phase 8–9 code, rendered by `scripts/primer-preview.mjs`.
- `R7-QQ-DAY.md`: the test plan and result of R7, the supervised day on QQ under the new design (run `r7-qq-11251644`, 2026-11-25).

The code implements this first design until the phases in `docs/ROADMAP.md` replace it.
